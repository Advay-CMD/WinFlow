# Getting Started with Explorer-CLI

Hi there!
Welcome to WinFlow! Here lets learn about WinFlow-Explorer-CLI!

## What is this?

Basically a minimalistic command prompt for file operations on a large scale. Made for WinFlow-Explorer, but you can use this otherwise too!

## What you need to know >

You need to have basic experience in CLI to use this.

## Somethings that are kept inefficent

The paths are the major disadvantage I would not like to change at ALL. There is no cd, pwd. This is kept to make it easy and reliable,also for the WinFlow-Explorer's sake, as UI will handle paths and the argument will be expanded like ```engine.exe ls C:\Users\Advay\```.
